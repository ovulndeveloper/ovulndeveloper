## Featured project

::: {align="center"}
### PixVelo Studio

**A desktop image-processing and optimization toolkit.**

`<a href="https://github.com/ovulndeveloper/PixVelo">`{=html}
`<img src="https://img.shields.io/badge/OPEN%20SOURCE-PixVelo-1f6feb?style=for-the-badge&logo=github" alt="Open PixVelo on GitHub" />`{=html}
`</a>`{=html}
:::

PixVelo is designed to bring image compression, conversion, batch
processing, cropping, previewing, and file workflow tools into one
desktop application.

  -----------------------------------------------------------------------
  Capability                          Project details
  ----------------------------------- -----------------------------------
  Image formats                       JPEG, PNG, WebP, AVIF, TIFF, BMP,
                                      ICO, PDF, GIF, TGA, RAW, HEIC,
                                      DICOM, and TINIX support

  Batch workflow                      Queue-based asynchronous processing

  Image preview                       Split-screen before/after
                                      comparison and pixel-difference
                                      preview

  Editing                             Crop presets and freeform cropping

  Processing                          Lanczos3 rendering, Zstandard
                                      pipeline, Pillow, OpenCV, and rawpy

  Desktop experience                  Dark mode, keyboard shortcuts, and
                                      portable distribution

  File workflow                       Cloud-folder detection for common
                                      sync providers
  -----------------------------------------------------------------------

**Explore the project:** [Source code, documentation, releases, and
issues](https://github.com/ovulndeveloper/PixVelo)
